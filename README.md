## 🎮 ระบบใหม่ที่อัปเกรด (New Features)

### 1. การโจมตีของศัตรูจะไม่ล็อกหรือหยุดการโจมตีของผู้เล่น (Unchained Action)
- ปลดล็อกข้อจำกัดเดิม: ผู้เล่นสามารถกดโจมตี ผสมคอมโบ หรือปล่อยสกิลได้ตลอดเวลา แม้บอสจะกำลังง้างดาบหรือกำลังฟันอยู่
- สไตล์การต่อสู้ดุดันขึ้น (Aggressive trades / Flow state) ผู้เล่นสามารถฟันแลกเลือด หรือกะจังหวะแดช/แพรี่สลับกับการรัวคอมโบได้อย่างอิสระ

### 2. ระบบคอมมานผสมท่าโจมตี (Command Combo Input Tree)
รองรับการกดด้วย **เมาส์คลิกซ้าย (LMB / ฟันเบา)** และ **เมาส์คลิกขวา (RMB / ฟันหนัก-แทง)** หรือปุ่ม Space / F บนคีย์บอร์ด:

| ลำดับการกด (Command) | ท่าคอมโบ (Combo Name) | อนิเมชั่น & ดาเมจ |
| :--- | :--- | :--- |
| **LMB** | **LIGHT SLASH I** | ฟันเฉียงขวาไปซ้าย (ดาเมจ 12) |
| **LMB ➔ LMB** | **LIGHT SLASH II** | ฟันตวัดหลังมือต่อเนื่อง (ดาเมจ 16) |
| **LMB ➔ LMB ➔ LMB** | **TRIPLE BLADE WALTZ** | กระโดดฟันกากบาทคู่ X พร้อมประกายดาบสองสี (ดาเมจ 26) |
| **LMB ➔ RMB** | **RISING FALCON CLEAVE** | ลอยตัวเสยดาบขึ้น เกิดคลื่นดาบจันทร์เสี้ยวเฉือนบอส (ดาเมจ 34) |
| **LMB ➔ LMB ➔ RMB** | **CYCLONE EXECUTION** | ควงดาบหมุน 360 องศาพายุหมุนรอบทิศ ประกายไฟระเบิด (ดาเมจ 45) |
| **RMB** | **STINGER THRUST** | พุ่งแทงดาบตรงระยะไกลทะลวงเกราะ (ดาเมจ 25) |
| **RMB ➔ LMB** | **VIPER RIPOSTE** | ดึงดาบกลับแล้วฟันกวาดตัดแนวนอนความเร็วสูง (ดาเมจ 30) |
| **RMB ➔ RMB** | **CRAG BREAKER** | ยกดาบใหญ่สองมือสแลมทุบพื้น รอยแยกแตกระเบิด (ดาเมจ 44) |

*มีแถบแสดงผลคอมมานบนหน้าจอทันทีเมื่อกด เพื่อให้เห็นสายคอมโบที่กำลังต่อติด!*

### 3. ศัตรูโจมตีต่อเนื่องเป็นชุด (Consecutive Boss Chains)
บอสไม่ได้ฟันแค่ทีเดียวแล้วจบอีกต่อไป แต่จะต่อคอมโบเป็นชุด (2 - 3 ฮิตต่อเนื่อง):
- **TWIN FANG (2 ฮิต)**: แทงเร็ว (แสงฟ้า — แพรี่) ➔ ฟาดหนักทันที (แสงส้ม — หลบ)
- **CRUSHER BARRAGE (2 ฮิต)**: ฟาดหนัก (แสงส้ม — หลบ) ➔ ทุบพื้นซ้ำ (แสงส้ม — หลบต่อเนื่อง)
- **IRON TEMPEST (3 ฮิต)**: แทงเร็ว 1 (แสงฟ้า) ➔ แทงเร็ว 2 (แสงฟ้า) ➔ ฟาดแผ่นดินไหวปิดท้าย (แสงส้ม)
- **VORTEX RIPOSTE (3 ฮิต)**: ฟันกวาด (แสงส้ม) ➔ แทงสวน (แสงฟ้า) ➔ สแลมจากด้านบน (แสงส้ม)
